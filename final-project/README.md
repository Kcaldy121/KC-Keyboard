# Audio to Notation System

This project captures user rhythm via keyboard input and pitch via microphone input, then processes the signal using the Web Audio API.

## Features
- Real-time pitch detection using AnalyserNode (FFT)
- Rhythm capture via keyboard timing
- Frequency-to-note mapping

## Technologies
- Web Audio API
- AnalyserNode
- JavaScript

## How to Run
Open index.html in a browser and allow microphone access.
